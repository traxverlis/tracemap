# tracemap
Discover your digital footprint. Take control of it.

## Digital Identity Manager

[`digital-identity-manager/`](digital-identity-manager/) is a private, self-hosted
Docker lab to audit **your own** digital identity: inventory your identifiers,
search for the public traces they left, validate every correlation yourself,
track your deletion requests and check that removed data does not reappear.

Start with [digital-identity-manager/README.md](digital-identity-manager/README.md).

It is meant exclusively for identities you own or are explicitly authorised to
audit, and it implements no way to bypass authentication, CAPTCHAs, anti-bot
protections or access controls.
